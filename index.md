## 🐾 Bem-vindo ao PetFinder Recife

O **PetFinder Recife** é uma plataforma web dedicada a ajudar donos de animais a reencontrarem seus pets desaparecidos na cidade do Recife. Nosso sistema permite registrar ocorrências e reportar avistamentos, criando uma rede de solidariedade rápida e acessível.

---

### ✅ O que o sistema oferece

* **Cadastro Seguro:** Criação de contas e login unificado.
* **Mural de Ocorrências:** Publicação de pets perdidos com foto, descrição detalhada e localização.
* **Busca e Filtros:** Encontre ocorrências específicas buscando pelo nome do pet ou do próprio dono.
* **Rede de Apoio:** Qualquer usuário da plataforma pode reportar avistamentos e pistas na página do animal desaparecido.
* **Gestão Total:** O dono tem autonomia para marcar o pet como encontrado e remover a ocorrência do feed principal quando a busca terminar.

### Tecnologias Utilizadas

O projeto foi construído do zero, integrando o backend e o frontend de forma fluida:
* **Backend:** C++17 com servidor HTTP (`httplib`)
* **Banco de Dados:** Relacional utilizando SQLite3
* **Frontend:** Interface web com HTML, CSS e JavaScript puro
